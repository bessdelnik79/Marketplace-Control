# Редактируемый макет Marketplace Control

Новые макеты с 8 октября 2026 сохраняются отдельно в [«Новый дизайн»](<Новый дизайн/README.txt>), в папках страниц по структуре переходов приложения. Редактируемый пакет, описанный ниже, и прежние одобренные изображения в `Makets` остаются историческими материалами; не смешивать их с новым набором.

Четыре экрана: desktop 1920×1080 и mobile 390×1150, каждый в светлой и тёмной теме. Мобильный экран сохраняет принятую структуру; desktop использует последний согласованный вариант. Дополнительно представлены календарь, справка, отсутствие срочных ситуаций и большой список проблем.

## Импорт с редактируемым текстом и компонентами

1. Откройте пустой Design-файл в приложении Figma Desktop.
2. В меню **Plugins → Development → Import plugin from manifest…** выберите `figma-import/manifest.json` из этой папки.
3. Запустите **Marketplace Control — Editable UI**.

Импортёр создаёт три страницы: «MC · Экраны», «MC · Компоненты», «MC · Стили». Тексты — обычные текстовые слои Inter, диаграммы — отдельные столбцы, повторяемые элементы — компоненты с текстовыми свойствами. Цвета привязаны к переменным; светлая и тёмная темы используют отдельные коллекции, совместимые со Starter. Плагин не обращается к сети, не удаляет существующие данные и не использует ключи доступа. Повторный импорт в тот же файл остановится, чтобы не создать дубликаты.

SVG-файлы можно перетащить в Figma для быстрого просмотра и правки векторов. Для сохранения текста именно текстовыми слоями используйте импортёр: при прямом SVG-импорте поведение текста зависит от Figma.

## Состав

- `desktop-light.svg`, `desktop-dark.svg` — макеты PC, 16:9.
- `mobile-light.svg`, `mobile-dark.svg` — принятый мобильный вариант.
- `states.svg` — дополнительные состояния и раскрытия.
- `styles.svg` — палитры, типографика и правила.
- `design-spec.json` — редактируемые исходные данные компоновки.
- `figma-import/` — автономный импортёр нативных слоёв.

Это дизайн-макет, а не подключённая к WB аналитика. Числа иллюстративные. Календари, вкладки и подсказки представлены состояниями; взаимодействия и расчёты приложения здесь не реализованы. Заказы и выкупы не сравниваются между собой. Диаграмма заказов сопоставляет каждый день со средним соответствующего дня за четыре предыдущих периода (текущие: 7/9/6/5/8/7, средние: 5/7/5/4/7/6).

## Воспроизведение и проверки

`node outputs/design/build-editable.mjs` пересобирает SVG, JSON и импортёр из одного источника.

`node --test outputs/design/editable.test.mjs` проверяет структуру, размеры, сравнения, темы и импортёр на модели API. Эти проверки не заменяют фактический запуск в Figma.

Проверка 13 сентября 2026: четыре локальных теста прошли; SVG-макеты основных экранов просмотрены после растеризации. Итоговый прогон на VM не выполнен: имя `marketplacecontrol` не разрешается, Hyper-V не предоставляет доступ к её сетевым параметрам. Изменения не затрагивают приложение или БД. Импортёр протестирован на модели API, но ещё не запущен в реальной Figma.

## Статус прямого переноса

Исправление 13 сентября 2026: импортёр явно загружает страницы перед чтением слоёв (`loadAllPagesAsync`). Проверка на модели API теперь запрещает чтение незагруженных страниц; все четыре локальных теста прошли. После прежней ошибки достаточно повторно запустить плагин: она возникала до создания страниц макета. Фактический успешный импорт в Figma пока не подтверждён.

[Созданный Figma-файл](https://www.figma.com/design/6lZOgZUjINEnD1NdHfx680) содержит предварительные переменные и стили. Прямая сборка экранов через подключение остановлена лимитом MCP на тарифе Starter. Готовые экраны находятся в этом пакете; нативный импорт в Figma ещё не выполнен.
