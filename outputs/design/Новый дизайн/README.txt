ПРАВИЛА ДАЛЬНЕЙШЕГО СОХРАНЕНИЯ

1. Все новые макеты сохранять внутри этой папки, а не в общей папке drafts или прежней Makets.
2. Новую самостоятельную страницу помещать в папку с её понятным русским названием.
3. Вложенную страницу помещать внутрь раздела, из которого пользователь на неё переходит.
4. Внутри папки страницы хранить варианты с именами:
   ПК-светлая-vN.png
   ПК-тёмная-vN.png
   Мобильная-светлая-vN.png
   Мобильная-тёмная-vN.png
5. N — номер версии. Не перезаписывать предыдущую согласованную версию без явного запроса.
6. Дополнительные состояния называть понятно: например ПК-светлая-ошибка-импорта-v1.png.
7. При добавлении страницы обновлять эту карту. Название папки может быть русским, URL не менять.
8. Запросы генерации и описания хранить в «Материалы генерации» с указанием страницы/набора и версии.
9. Согласование дизайна не означает разрешение внедрять его в приложение без отдельного запроса.
