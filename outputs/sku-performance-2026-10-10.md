# Производительность карточек SKU — 10 октября 2026

## Причина и исправление

План PostgreSQL переставлял соединения при чтении источников карточки: поиск операции через `coalesce` превращался в повторные проходы по дате и товару. Мартовский снимок: 180 480 проходов по `operation_versions`, 1,26 млн попаданий в shared buffers, 2,5 секунды на SQL источников.

Коррелированный `LATERAL` с `OFFSET 0` сохраняет поиск операции по ID. Tenant, дата, SKU, активность, методика, сумма вклада и замороженная пара версии отчёта/нормализации проверяются как раньше. Схема БД не меняется.

Карточка обогащает источниками только выбранную SKU. Общая модель и финансовая сверка всего опубликованного scope сохранены. Метаданные группируются один раз по группе и строке, без повторного просмотра всех источников для каждого товара.

## Повторное открытие

Кэш в памяти страницы: максимум 20 успешных карточек, 60 секунд без продления при чтении. Ключ: магазин, источник, ID публикации, начало/конец периода, SKU. Сортировка и поиск не меняют финансовый контекст. После обновления страницы или истечения срока выполняется обычный HTTP-запрос с проверкой авторизации и тарифа. Ошибки, отменённые запросы и несовпадающий контекст не сохраняются. Общий серверный кэш не вводился.

## ВМ

Две vCPU. Карточки и полные списки за март и август сравнивались целиком до/после: значения, источники, продажи, возвраты, недельные результаты и контексты совпали.

- Март: карточка 2 714 мс до, 278 мс после (включая отдельный `EXPLAIN ANALYZE`); SQL источников 85 мс.
- Август: 352 мс до, 62 мс после; SQL источников 29 мс.
- Новый мартовский план: 46,6 мс, 16 342 shared hits, 43 прохода по операциям.
- Три одновременные карточки августа: 193 мс суммарного времени. Это проверка небольшой конкуренции, а не предела пользователей.

Проверки читают опубликованные данные обычной ролью приложения без запросов к WB. На ВМ прошли 757 тестов приложения и 179 проверок БД (106 таблиц); дополнительно прошли 5 тестов метаданных, включая новую проверку изоляции между SKU. Независимое ревью не выявило блокирующих замечаний.
