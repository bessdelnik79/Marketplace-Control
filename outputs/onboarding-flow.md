# Первый вход и магазины

После регистрации создаются пользователь, бизнес и бесплатная подписка. Магазин автоматически не создаётся.

Если у пользователя нет магазина, `/` направляет его на `/onboarding/store`. На первом шаге пользователь задаёт понятное ему название магазина. Созданный магазин имеет статус `paused`, не содержит внешнего идентификатора WB и не считается подключённым.

До подключения Wildberries обзор показывает честное пустое состояние без демонстрационных показателей. В настройках видны название магазина, статус «Не подключён» и форма API-токена. Токен проверяется официальными методами WB, после чего сохраняется только в зашифрованном виде. Пока первая загрузка статистики не завершена, обзор также не показывает демонстрационные суммы.

Добавить магазин можно из настроек. Количество магазинов ограничивается действующим тарифом на уровне БД. На бесплатном тарифе доступен один магазин.

Защищённые страницы доступны только с действующей пользовательской сессией. Неавторизованный запрос направляется на `/login`; после входа сервер выбирает обзор или первый шаг настройки в зависимости от наличия магазина.

После первого сохранения WB-ключа сначала загружается финансовая история за год. Первичная оперативная фабрика последнего месяца ожидает подтверждённого покрытия этой истории и показывает «Ожидаем финансовых отчётов». Затем возвраты закрытых недель берутся из принятых финансовых исходников, сохранённые оперативные дни используются повторно, а WB запрашивается только для недостающего покрытия. Успех получения списка финансовых отчётов без принятых деталей не разблокирует фабрику.
