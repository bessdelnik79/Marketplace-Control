# Внедрение внутренних макетов настроек — 8 октября 2026

## Результат

В существующее серверное приложение перенесены восемь внутренних страниц согласованного нового дизайна. Источники расположены в `outputs/design/Новый дизайн/Настройки/` по структуре переходов. Нового прототипа, внешних зависимостей или параллельных формул не добавлено.

| Переход | Страница |
| --- | --- |
| Данные для расчёта → Себестоимость товаров | `/costs` |
| Данные для расчёта → Дополнительные расходы | `/expenses` |
| Данные для расчёта → Налоги | `/taxes` |
| Товары для анализа | `/products` |
| Загрузки по API | `/settings/data` |
| Тарифный план | `/tariff` |
| Аккаунт → Изменение пароля | `/password` |
| Аккаунт → Удаление аккаунта | `/account/delete` |

Общие компоненты: кнопка возврата, заголовок, карточки, палитры и мобильная компоновка. CSS себестоимости изолирован точным маршрутом, чтобы не менять соседние страницы с историческим классом `costs-page`.

## Сохранённые контракты

- Данные аккаунта, каталог, лимиты и финансовые статусы остаются серверными; образцы из макетов не подставляются пользователям.
- Формы отправляются в прежние защищённые обработчики, сохраняют имена полей, даты действия, версии, импорт/аннулирование и ошибки. Пароли не сохраняются в браузере.
- Сохранённое намерение тарифа отделено от фактического оплаченного доступа.
- Финансовые метаданные публикуются через прежний status endpoint и обновляются существующим polling. Ошибки/повторные попытки не скрыты; незаполненные значения не превращаются в нули.
- Формулы, БД, авторизация и алгоритмы WB-синхронизации не изменены.
